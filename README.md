# Les Petites Bêtises

Petite PWA familiale pour suivre les bêtises et les bonnes actions des enfants.

- Compteurs indépendants midi / soir
- Demi-bêtises et bêtises entières
- Photos des enfants stockées localement
- Couronne à zéro et animation lors d'une bêtise
- Enfants de la famille et enfants accueillis
- Bonnes actions et historique du jour
- Fonctionnement hors ligne après le premier chargement

## Publication

Le site est prévu pour GitHub Pages depuis la branche `main`, dossier `/ (root)`.

Les données saisies dans l'application restent dans le stockage local du navigateur de l'appareil.
